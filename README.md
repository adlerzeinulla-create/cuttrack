# CUTTRACK 0.1v — трекер сушки и зала

Мобильное PWA-приложение по мотивам видео **bigpro427 «EVERYTHING YOU WILL EVER NEED TO KNOW ABOUT DIETING»**. Работает на iPhone и Android как обычное приложение: открыл с домашнего экрана — и всё под рукой. Данные хранятся только на устройстве.

## Что нового в 0.1v

- **База продуктов выросла до 126 позиций** — КБЖУ и клетчатка на 100 г из открытого датасета USDA FoodData Central SR Legacy.
- **Раздел «Меню»** — готовый план питания на день, неделю и месяц с порциями под твои калории и БЖУ.
- **Кухни и рецепты** — 6 кухонь (СНГ, Средняя Азия, Кавказ, Восток, Средиземноморье, бюджетный зал), 24 готовых меню и 45 рецептов с ингредиентами и шагами приготовления.
- **Аллергии** — 9 аллергенов: глютен, молочное, яйцо, рыба, морепродукты, соя, орехи, арахис, кунжут. Продукты и рецепты с аллергенами скрываются или помечаются предупреждением.
- **Вода** — дневник воды с авто-нормой по весу и активности, ручной целью и графиком за 7 дней.
- **Добавление плана в дневник** — одним нажатием: отдельный приём, весь день, неделя, месяц, рецепт или целое меню.
- **Шагомер и датчики** — аппаратный шагомер Android, акселерометр и гироскоп. В PWA на iPhone — экспериментальный подсчёт по движению, пока приложение открыто.
- **Версия 0.1v** — в шапке приложения, манифесте и Android-сборке.

## Что внутри

- **Питание** — дневник по приёмам пищи, калории, БЖУ, клетчатка, 126 продуктов, свои блюда, источник и FDC ID у каждого продукта.
- **Меню** — план на день/неделю/месяц: завтрак, обед, ужин и перекус; порции, КБЖУ, клетчатка и подсказки. План детерминированный: один и тот же день даёт одинаковый набор.
- **Кухни** — режим «Кухни» в разделе «Меню»: готовые меню на день по кухням, с составом блюд и добавлением в дневник одним нажатием.
- **Рецепты** — каталог с поиском и фильтрами по кухне и приёму пищи; у каждого рецепта граммовки, КБЖУ, шаги приготовления и подсказка.
- **Аллергии** — профиль → «Аллергии» или шаг онбординга. Конфликтующие продукты скрываются из подбора, рецепты с аллергенами нельзя добавить, блюда в меню помечаются. Переключатель «Показать с аллергенами» возвращает их в список с предупреждением.
- **Вода** — карточка в «Питании», быстрые кнопки +250/+500/+1000 мл, ручной ввод, норма и график за 7 дней в «Прогрессе».
- **Расчёт** — BMR/TDEE, умеренный или агрессивный дефицит, лимит по % жира (31–41 ккал на фунт), темп 1–1,5% в неделю.
- **Макросы** — белок 0,8–1 г/фунт, жиры 0,3–0,5 г/фунт, углеводы остатком.
- **Шаги** — дневник шагов с оценкой калорий, целью и предупреждением о 25 тыс.
- **Зал** — шаблоны Upper/Lower, Full Body, PPL, база 50+ упражнений, подходы/повторы/RIR, таймер отдыха, история и объём.
- **Прогресс** — вес, среднее за 7 дней, график, темп, шаги и статистика тренировок.
- **Гайд** — сжатые правила из видео по дефициту, углеводам, сытости, тренировкам, добавкам и выходу из диеты.
- **Экспорт/импорт** — JSON-файл со всеми данными.

## Откуда еда

- **USDA FoodData Central, SR Legacy (April 2018)** — 124 продукта, public domain. Значения на 100 г: калории, белок, жиры, углеводы, клетчатка. У каждого продукта есть `fdcId`, по которому данные можно проверить на [fdc.nal.usda.gov](https://fdc.nal.usda.gov/).
- **Open Food Facts** — средние рыночные значения для whey-протеина и скира (2 позиции), отмечены в поле `src`.
- Русские названия, категории, роли, теги приёмов пищи и размеры порций — в `data/food_map.json`. Сам `js/foods.js` генерируется скриптом `CutTrackAndroid/.tools/build-foods.ps1`; вручную его лучше не править.
- Проверка целостности: `CutTrackAndroid/.tools/validate-foods.ps1` → отчёт `food-validation.txt` (0 отсутствующих FDC ID, 0 подозрительных значений).

## Быстрый старт

Можно открыть `index.html` в браузере, но для установки на iPhone и офлайн-режима нужен HTTP/HTTPS-адрес — ниже варианты.

### Вариант 1. GitHub Pages (бесплатно)

1. Создай репозиторий на GitHub.
2. Загрузи содержимое папки `CutTrack` (не саму папку, а файлы внутри).
3. Settings → Pages → Branch: `main`, папка `/(root)` → Save.
4. Через минуту приложение будет по адресу `https://<ник>.github.io/<репозиторий>/`.

### Вариант 2. Netlify Drop

1. Зайди на [app.netlify.com/drop](https://app.netlify.com/drop).
2. Перетащи папку `CutTrack`.
3. Получи ссылку — её можно открыть на iPhone.

### Установка на iPhone

1. Открой ссылку в **Safari** (не в Chrome).
2. Кнопка «Поделиться» → **«На экран “Домой”»**.
3. Название — `CUTTRACK` → «Добавить».
4. Запускай с иконки: приложение откроется без адресной строки и будет работать офлайн.

## Кухни, рецепты и аллергии

- **Кухни:** СНГ · домашняя, Средняя Азия, Кавказ, Восток, Средиземноморье, Бюджет · зал. В каждой — 4 меню на день, всего 24. Меню собраны из рецептов и продуктов текущей базы, без новых позиций.
- **Рецепты:** 45 штук с граммовками, КБЖУ на порцию, шагами приготовления и тегами (быстро, много белка, бюджетно и т.д.). Каталог открывается из «Питания» и из режима «Кухни».
- **Добавление:** рецепт или меню добавляются в выбранный день; повторное добавление не дублирует продукты — у записей есть `planId`.
- **Аллергены:** `gluten`, `dairy`, `egg`, `fish`, `seafood`, `soy`, `nuts`, `peanut`, `sesame`. Разметка хранится у продуктов, рецептов и записей дневника; старые записи сопоставляются по названию продукта.
- **Логика:** при выбранной аллергии конфликтующие продукты скрыты из поиска, рецепт с аллергеном открывается для просмотра, но не добавляется, а при добавлении меню проблемные блюда пропускаются с сообщением.
- **Важно:** разметка аллергенов — ориентир по составу продуктов, а не медицинская гарантия. При тяжёлой аллергии проверяй упаковку и состав.

## Вода

- Норма в авто-режиме: **30 мл × вес + поправка на активность** (мало 0, средне 150, много 300, очень много 450 мл), ограничение 1500–4500 мл, округление до 50 мл.
- Ручную цель можно задать в профиле или в карточке воды: 500–6000 мл. Кнопка «Вернуть авто-норму» сбрасывает ручное значение.
- Вода хранится по дням, участвует в экспорте/импорте и показывается на графике за 7 дней в «Прогрессе».

## Шагомер и датчики

- **Android APK** — аппаратный `TYPE_STEP_COUNTER` или `TYPE_STEP_DETECTOR`; если их нет — акселерометр с проверкой по гироскопу. На Android 10+ приложение попросит разрешение «Физическая активность».
- **PWA на iPhone** — экспериментальный подсчёт по `DeviceMotionEvent`: акселерометр считает шаги, гироскоп отсекает ложные движения. iOS не отдаёт данные HealthKit/CMPedometer веб-приложению, поэтому счёт идёт только пока приложение открыто и экран активен.
- **Ручной ввод** всегда доступен: Питание → шаги → «Изменить». При сохранении ручных шагов активный датчик останавливается, чтобы значения не перезаписались.
- **Гироскоп** — дополнительный сигнал, а не самостоятельный шагомер: он помогает не считать шагом резкие повороты телефона.

## Локальный запуск

Из-за service worker лучше запускать через HTTP, а не `file://`. На Windows проще всего встроенным сервером:

```powershell
# в папке CutTrack
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```

Затем открой `http://localhost:8765`. Альтернативы: `python -m http.server 8080` или `npx serve .`.

## Android APK

Готовая debug-сборка: `CutTrackAndroid/CUTTRACK-0.1v-debug.apk` (WebView-обёртка с локальным HTTP-сервером и нативным шагомером). Подробности сборки и установки — в `CutTrackAndroid/README.md`.

## Резервная копия

Профиль → «Экспорт» сохраняет JSON со всеми данными (питание, вес, тренировки, настройки). «Импорт» восстанавливает его на этом или другом устройстве. В Android-сборке JSON сохраняется в «Загрузки».

## Структура

```
CutTrack/
  index.html            # каркас и meta для iOS
  css/styles.css        # тёмная тема, мобильная вёрстка
  js/foods.js           # сгенерированная библиотека 126 продуктов с аллергенами
  js/data.js            # продукты, упражнения, шаблоны, гайд, план, кухни, рецепты, меню
  js/app.js             # логика, расчёты, планировщик, кухни, аллергии, вода, датчики
  data/food_map.json    # русские названия → FDC ID, роли, порции, теги, аллергены
  manifest.webmanifest  # PWA-манифест
  sw.js                 # офлайн-кэш (network-first, cuttrack-v4)
  icons/                # иконки 180/192/512
  serve.ps1             # локальный сервер для Windows
  make-icons.ps1        # генератор иконок (Windows)
```

## Важно

Приложение считает **ориентиры**, а не ставит диагноз. Это не медицинская рекомендация. При проблемах со здоровьем, подросткам, беременным и людям с расстройствами пищевого поведения нужен специалист.
